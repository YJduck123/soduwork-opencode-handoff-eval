# 日志拾光

一个纯本地的 JSONL 日志查看小工具。中文界面，无第三方依赖、无构建步骤，双击 `index.html` 即可使用。

## 运行

直接双击 `index.html`，或把它拖进浏览器。

- 选文件：选择本机的 `.jsonl` / `.log` / `.txt` 文件。
- 载入示例：读取内置的示例日志（与根目录 `sample.jsonl` 内容一致）。
- 粘贴日志：把 JSONL 文本贴进文本框后点“分析粘贴内容”。

所有解析都在浏览器本地完成，页面不会发起网络请求。

## 已实现

- 逐行解析 JSONL，字段为 `timestamp`、`level`、`service`、`status`、`duration_ms`、`message`。
- JSON 错误或字段类型不正确的行单独跳过，并显示真实物理行号、原因和内容预览；其他行照常载入。
- 级别、服务、关键词组合筛选（AND）；关键词在 `service` 和 `message` 中不区分大小写匹配。
- 实时统计当前筛选结果的记录数、ERROR 数、慢请求数（`duration_ms >= 1000`）和平均耗时。
- 将当前筛选结果导出为 CSV：固定六字段、UTF-8 BOM、CRLF 行尾，正确转义逗号、双引号和消息内换行。
- 消息中的引号、换行、HTML 标签全部按普通文本展示，不执行任何标记。
- 空结果、全无效文件、从未载入等状态都有独立提示。

## 目录

```text
index.html              页面结构
styles.css              视觉与响应式布局
js/core.js              纯函数：解析、校验、统计、筛选、格式化
js/app.js               DOM 渲染与事件绑定
js/sample-data.js       由 sample.jsonl 自动生成的内嵌示例
sample.jsonl            原始示例日志（未修改）
scripts/embed-sample.js 重新生成 js/sample-data.js 的开发脚本
tests/core.test.js      核心行为检查
```

双击打开时浏览器会限制 `file://` 页面读取相邻文件，因此“载入示例”使用内嵌副本。`sample.jsonl` 保持原样；如果以后修改了它，运行 `node scripts/embed-sample.js` 同步，测试会校验两者完全一致。

## 行为检查

```bash
node --test tests/core.test.js
```

当前结果：17 项全部通过。

覆盖内容包括：

- 示例文件 10 行中保留 8 条有效记录，跳过第 9、10 行；
- 每种字段类型错误、缺失字段、非 JSON 对象、坏 JSON 都能逐行隔离，后续有效行不丢失；
- 空行、CRLF、UTF-8 BOM 处理，坏行行号按原始物理行计算；
- 慢请求边界：999 不算，1000 和 1001 都算；
- 级别、服务、关键词组合筛选，以及大小写、首尾空白、换行消息匹配；
- 空结果统计、平均值格式、筛选选项排序；
- CSV 的 BOM、表头顺序、CRLF、逗号/双引号/中文/换行转义、筛选结果与空记录；
- 内嵌示例与 `sample.jsonl` 字节级一致。

另外已用隔离浏览器实际打开页面验证：示例统计 8 / 3 / 3 / 750.0ms，ERROR 筛选后 3 条、平均 1486.7ms，文件选择可正常读取，关键词和服务组合筛选生效，空结果提示正确，带 HTML 标签和换行的粘贴消息只显示为文本，控制台无报错。CSV 序列化由上面的 Node 测试覆盖，下载按钮的浏览器交互尚未实测。
